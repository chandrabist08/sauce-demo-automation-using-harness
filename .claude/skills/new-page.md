---
description: Scaffold a new Page Object and matching spec file skeleton
---

Ask the user:
1. Feature name (e.g. "billing")
2. Page name (e.g. "invoice-list")
3. Key user actions on this page (e.g. "click create button, search invoices, delete invoice")

Then invoke the `pom-creator` agent to generate the Page Object, then invoke the `test-generator` agent to generate the matching spec.

Report both file paths when done.
