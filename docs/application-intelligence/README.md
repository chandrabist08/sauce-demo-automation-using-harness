# Application Intelligence

This directory contains project context documents that inform agent behaviour.

## Project context
- [`_template/project-context.md`](_template/project-context.md) — Saucedemo app overview, auth, user roles, constraints

## Module contexts
- [`_template/module-context.md`](_template/module-context.md) — Inventory module (REQ-001–REQ-005)
- [`cart-module-context.md`](cart-module-context.md) — Cart module (REQ-006–REQ-009)
- [`checkout-module-context.md`](checkout-module-context.md) — Checkout module (REQ-010–REQ-014)

## Templates
- `_template/requirement.example.json` — copy for each approved requirement

## Adding a new module
1. Copy `_template/module-context.md` to `<module>-module-context.md`
2. Fill all sections from DISCOVER output
3. Add a row to the index above
